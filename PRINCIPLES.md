# Architecture Principles

These principles guide the work in this repository.

1. **Start with the problem, not the technology.**
2. **Make requirements and quality attributes explicit.**
3. **Prefer simple architectures until complexity is justified.**
4. **Design for failure, not only the happy path.**
5. **Make contracts explicit and versioned.**
6. **Secure every identity, request, tool and data path by default.**
7. **Make state and ownership explicit.**
8. **Prefer measurable trade-offs over intuition.**
9. **Observe systems end-to-end.**
10. **Treat evaluation as a production capability in AI systems.**
11. **Design for change, migration and deprecation.**
12. **Record important decisions and their consequences.**
13. **Automate repeatable infrastructure and delivery.**
14. **Keep tenant boundaries explicit.**
15. **Measure cost as a first-class architecture attribute.**
16. **Use deterministic controls around probabilistic AI.**
17. **Build progressively; avoid premature complexity.**
