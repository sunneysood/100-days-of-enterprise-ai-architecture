# Learning Policy

This repository deliberately avoids becoming a collection of courses.

## When to study

Study a topic when:

1. the roadmap calls for it, or
2. the current implementation exposes a real knowledge gap.

## When to add a resource

Add a resource only when it provides one of:

- a missing mental model
- a stronger implementation technique
- a production case study
- a new architectural capability

## What does not count

Course and playlist completion are not themselves evidence of engineering capability.

## Core loop

**Understand → Rebuild → Extend → Break → Measure → Document**
