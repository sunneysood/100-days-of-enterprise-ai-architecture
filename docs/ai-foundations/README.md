# AI Foundations

The technical articles in this directory cover foundational concepts that support later work in RAG, agent systems, evaluation and LLM infrastructure.

| Article | Role in the journey |
|---|---|
| [From If-Then Rules to ChatGPT: How AI Really Learned to "Think"](./from-if-then-rules-to-chatgpt.md) | Establishes the historical progression from traditional programming and symbolic AI through machine learning, neural networks, RNNs, attention, Transformers and LLMs. |
| [How Large Language Models Actually Work: From Your Prompt to Every Word They Write](./how-large-language-models-actually-work.md) | Builds the mechanical mental model from tokens and embeddings through attention, Q/K/V, Transformer layers, logits, decoding and autoregressive generation. |
| [Tokens & Tokenizers: How a Computer "Reads" a Sentence](./tokens-and-tokenizers.md) | Goes deeper into tokenization, BPE, tokenizer families, token IDs, token order, contextual meaning and a runnable mini-BPE implementation. |
