## Evidence Rules

A day is considered complete when there is at least one tangible artifact:

- code
- architecture diagram
- experiment
- benchmark
- ADR
- test
- runbook
- threat-model entry
- cost analysis
- written architectural explanation

Watching a video alone does not count as evidence.
